# agents/baseline/

Generalist-agenter, én markdown-fil pr. rolle: analyst, spec og planner (produktafdelingen, workflowet `idea`), implementer, reproducer og reviewer.

Projekt- og domæneagenter i `<projekt>/.factory/agents/` arver fra disse filer via `extends`. Formatet og reglerne for, hvilken agent der vælges, står i `docs/agents.md`.
