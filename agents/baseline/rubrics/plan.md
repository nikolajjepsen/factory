# Rubric: implementation plan

Score each point. Start at 10 and subtract.

- **Covers the issue (−4 if not).** The plan addresses every acceptance criterion in the issue and spec.
- **Concrete (−2 to −3).** It names the files to change, the functions to add or change, and the tests to write.
- **Fits the codebase (−1 to −2).** It reuses existing code and follows the project's AGENTS.md instead of inventing new patterns.
- **Right-sized (−1 to −2).** No work outside the issue's scope.

`passed` is true only when the score is at least 7 and the first point holds.
